## Import steps (show these to the user)

1. Download the course's `.ics` file (open its link, then save the file).
2. On a computer, open Google Calendar → **Settings** (gear) → **Import & export** → **Import** → choose the file → **Add to calendar:** your main calendar → **Import**. (The phone app can't import files.)
3. Start a new study chat with your usual start prompt. The course appears under **Self-study courses**.

Each course's dates are fixed in the file. Importing the same file again updates its events instead of duplicating them. To remove a course, delete its events from your calendar, then archive it in the study chat (`ARCHIVE n`).
