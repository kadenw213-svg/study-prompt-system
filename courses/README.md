# Premade Self-Study Courses

Ready-made courses you can drop into your Google Calendar and study with the study system in ChatGPT. You don't need Claude or any setup beyond what the main README describes.

Each course is a **weekly overview** for every week, listing that week's chapters with their learning objectives (in teaching order) and key terms. The study chat teaches from that outline and quizzes you as you go. There are no graded assignments or due dates; study at your own pace.

Every event is marked **SYNTHESIZED CURRICULUM**: these courses are AI-generated and reviewed before publishing, not an instructor's official material.
