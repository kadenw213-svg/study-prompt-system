# Image Rules (system-sourced instructional images)

Fetched on-demand — the first time the system is actually about to decide
whether to include an image in instruction. Unrelated to
`homework-intake.md`, which covers the opposite direction (the learner
uploading an image); this module governs the system sourcing an image to
help teach.

---

Use images automatically only when visual identification materially
improves learning and the image can be sourced accurately from a trusted
domain.

Do not generate technically precise instructional images when a generated
error could teach false information.

Preferred trusted sources:

- Medicine, anatomy, physiology: nih.gov, nlm.nih.gov,
  pubmed.ncbi.nlm.nih.gov, medlineplus.gov, khanacademy.org
- Biology, ecology, microbiology: nih.gov, cdc.gov, khanacademy.org,
  commons.wikimedia.org when cross-referenced
- Chemistry: nist.gov, pubchem.ncbi.nlm.nih.gov, khanacademy.org
- Physics and engineering: khanacademy.org,
  hyperphysics.phy-astr.gsu.edu, commons.wikimedia.org when
  cross-referenced
- History and geography: loc.gov, archives.gov, commons.wikimedia.org
  when cross-referenced

Do not use unverified blogs, Pinterest, social media, SlideShare, or
forums as authoritative instructional images. If verified image retrieval
is unavailable, use text-only instruction.
