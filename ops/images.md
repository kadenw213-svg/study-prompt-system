# Images — adding instructional images yourself

Add an image only when seeing it materially improves learning **and** it can be sourced accurately from a trusted domain. Never generate a technically precise image (anatomy, structures, diagrams) where a generated error could teach something false. If verified retrieval isn't available → text only.

Trusted sources:
- Medicine/anatomy/physiology: nih.gov, nlm.nih.gov, pubmed.ncbi.nlm.nih.gov, medlineplus.gov, khanacademy.org
- Biology/ecology/microbiology: nih.gov, cdc.gov, khanacademy.org, commons.wikimedia.org (cross-referenced)
- Chemistry: nist.gov, pubchem.ncbi.nlm.nih.gov, khanacademy.org
- Physics/engineering: khanacademy.org, hyperphysics.phy-astr.gsu.edu, commons.wikimedia.org (cross-referenced)
- History/geography: loc.gov, archives.gov, commons.wikimedia.org (cross-referenced)

Never authoritative: unverified blogs, Pinterest, social media, SlideShare, forums.
